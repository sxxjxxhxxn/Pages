1. 처리하는 정보와 목적

  • 프로젝트와 도안 파일: 프로젝트 이름, 뜨개 종류, 진행 상태, 도안 편집 내용과 첨부한 PDF는 프로젝트 관리 기능을 위해 기기에 저장됩니다. 별도 회원 가입이나 로그인이 필요하지 않습니다.
  • AI 도안 분석: 사용자가 분석을 선택하고 앱의 안내에 동의한 경우에만, 파일 이름과 선택한 PDF에서 기기 내 추출한 텍스트 및 분석에 필요한 페이지 이미지가 Google Cloud Run을 거쳐 Google Gemini API로 전송됩니다. AI는 도안의 파트·단계·옵션을 정리합니다. 선택한 PDF에서 최대 40페이지를 분석하며, 40페이지를 넘으면 분석할 범위를 선택할 수 있습니다. 분석 결과와 원본 첨부는 프로젝트를 저장하면 기기에 저장됩니다.
  • 무료 분석 횟수와 이용권: 최초 무료 2회와 구매 크레딧 잔액을 서버에서 관리합니다. 앱은 Apple이 서명한 앱 거래 및 구매 거래 증명을 Cloud Run에 보내며, 서버는 서명을 검증합니다. 앱 거래 식별자, 구매 거래 식별자, 상품 및 남은 크레딧은 Google Cloud Firestore에 저장되어 중복 지급과 환불을 처리하는 데 사용됩니다. 서명 증명과 도안 파일은 이 이용권 장부에 저장하지 않습니다.
  • 구매: 잠금 해제 구매와 복원은 Apple StoreKit을 이용합니다. 결제 정보는 Apple이 처리하며 Heize는 카드 정보를 받지 않습니다.
  • 카메라: 게이지 측정 등 사용자가 해당 기능을 선택할 때만 접근합니다.

2. 외부 서비스와 처리

  • Google Cloud Run 및 Firestore: AI 요청 전달, 이용권 확인 및 남용 방지를 위해 요청 IP 주소를 처리하며, Cloud Run 서비스 요청 로그에 접속 메타데이터가 기록될 수 있습니다. Firestore에는 앱 거래 식별자, 구매 거래 식별자, 상품, 이용권 잔액 및 분석 세션 상태가 저장됩니다. 거래 기록은 중복 지급과 환불 처리를 위해 사용됩니다. PDF, 도안 내용, Gemini 프롬프트와 응답은 Firestore 이용권 장부에 저장하지 않습니다.
  • Google Gemini API (유료 서비스): 현재 Cloud Billing이 연결된 유료 Gemini API 서비스를 사용합니다. Google은 이 유료 서비스에서 프롬프트와 응답을 Google 제품 개선에 사용하지 않지만, 악용 정책 위반을 탐지·방지하기 위해 제한된 기간 보관할 수 있습니다. 자세한 내용은 Gemini API 약관과 데이터 보관 안내를 확인해 주세요.

민감하거나 기밀인 정보를 포함한 도안은 AI 분석에 보내지 마세요. 광고·추적 SDK는 사용하지 않습니다.

3. 보관과 삭제

프로젝트와 첨부 파일은 사용자가 프로젝트를 삭제하거나 앱을 삭제할 때까지 기기에 보관됩니다. 앱은 백그라운드로 전환될 때 마지막 정상 상태의 프로젝트와 첨부 파일을 앱 전용 저장 공간에 자동 백업하며, 저장소 오류가 발견되면 손상된 저장소와 첨부 파일도 별도 사본으로 보존합니다. 앱에서 내보내는 복구 백업에는 프로젝트 데이터와 첨부 파일이 포함됩니다. 사용자가 백업을 내보내면 선택한 위치에 별도 파일로 보관되며 앱 삭제 시 자동 삭제되지 않으므로 직접 삭제해야 합니다.

AI 분석을 위해 Google Cloud Run을 거쳐 전송된 PDF 내용과 분석 응답은 Gemini 처리를 위해 사용됩니다. Heize는 이를 Firestore 이용권 장부에 저장하지 않습니다. 외부 서비스의 처리 및 보관은 각 제공자의 정책과 서비스 조건을 따릅니다.

4. 문의와 권리

기기에서 프로젝트와 첨부 파일을 삭제할 수 있습니다. 개인정보 관련 문의는 rv6qxfg9mm@privaterelay.appleid.com로 연락해 주세요.

Privacy Policy

Last updated: 2026-10-16
Operator: Jaehun Seo (Heize)
Contact: rv6qxfg9mm@privaterelay.appleid.com

1. Information and purposes

  • Projects and pattern files: Project names, craft type, progress, edited pattern content, and attached PDFs are stored on the device to provide project management. No separate account or sign-in is required.
  • AI pattern analysis: Only when you request analysis and agree to the in-app notice, the file name, text extracted on the device from the selected PDF, and page images needed for analysis are sent through Google Cloud Run to the Google Gemini API. AI organizes pattern sections, steps, and options. Up to 40 selected PDF pages are analyzed; for longer PDFs you can choose a range. The source attachment and analysis result are stored on the device when you save the project.
  • Free analyses and credits: The server manages the first two free analyses and purchased credits. The app sends Apple-signed app and purchase transaction proofs to Cloud Run for verification. Firestore stores the app transaction identifier, purchase transaction identifiers, product, and remaining balance to prevent duplicate credits and process refunds. Signed proofs and pattern files are not stored in this credit ledger.
  • Purchases: Unlock purchases and restoration use Apple StoreKit. Apple processes payment information; Heize does not receive card details.
  • Camera: Accessed only when you choose a feature that needs it, such as gauge measurement.

2. Third-party services

  • Google Cloud Run and Firestore: Process request IP addresses to route AI requests, check access, and prevent abuse. Cloud Run request logs may also contain access metadata. Firestore stores app and purchase transaction identifiers, product, credit balance, and analysis session state. Transaction records support duplicate prevention and refund processing. PDFs, pattern content, Gemini prompts, and responses are not stored in the Firestore credit ledger.
  • Google Gemini API (paid service): Heize currently uses the paid Gemini API service with Cloud Billing connected. Google does not use prompts and responses from this paid service to improve Google products, but may retain them for a limited period to detect and prevent abuse policy violations. See the Gemini API Terms and data retention information.

Do not submit patterns containing sensitive or confidential information for AI analysis. Heize does not use advertising or tracking SDKs.

3. Retention and deletion

Projects and attachments remain on the device until you delete a project or remove the app. When the app moves to the background, it automatically saves a last-known-good copy of project data and attachments in app-only storage. If a store error is detected, the damaged store and attachment files are also preserved separately. Recovery backups exported from the app include project data and attachments. An exported backup is saved to a location you choose and is not automatically deleted when you remove the app; delete it yourself.

PDF content and responses sent through Google Cloud Run are processed by Gemini for AI analysis. Heize does not store them in the Firestore credit ledger. External providers' processing and retention are governed by their policies and service terms.

4. Contact and your choices

You can delete projects and attachments in the app. For privacy questions, contact rv6qxfg9mm@privaterelay.appleid.com.

5. Changes

When this policy changes, the last updated date on this page will be revised.
