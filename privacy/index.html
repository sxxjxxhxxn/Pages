1. 처리하는 정보와 목적

  • 프로젝트와 도안 파일: 프로젝트 이름, 뜨개 종류, 진행 상태, 도안 편집 내용, 첨부한 PDF·사진은 프로젝트 관리 기능을 위해 기기에 저장됩니다. 별도 회원 가입이나 로그인이 필요하지 않습니다.
  • AI 도안 분석: 사용자가 분석을 선택하고 앱의 안내에 동의한 경우에만, 파일 이름과 선택한 PDF·사진에서 기기 내 추출한 텍스트 및 분석에 필요한 페이지 이미지가 Cloudflare Worker를 거쳐 Google Gemini API로 전송됩니다. AI는 도안의 파트·단계·옵션을 정리합니다. 선택한 PDF의 최대 40페이지를 분석하며, 40페이지를 넘으면 분석할 범위를 선택할 수 있습니다. 분석 결과와 원본 첨부는 프로젝트를 저장하면 기기에 저장됩니다.
  • 무료 분석 횟수: 남은 분석 횟수는 Apple iCloud Key-Value Store를 통해 동기화될 수 있습니다. 프로젝트 내용과 도안 파일은 이 기능으로 동기화되지 않습니다.
  • 구매: 잠금 해제 구매와 복원은 Apple StoreKit을 이용합니다. 결제 정보는 Apple이 처리하며 Heize는 카드 정보를 받지 않습니다.
  • 카메라: 게이지 측정 등 사용자가 해당 기능을 선택할 때만 접근합니다.

2. 외부 서비스와 처리

  • Cloudflare: 요청 전달과 IP별 요청 제한을 위해 요청 IP 주소를 처리합니다. Heize Worker 코드는 요청 본문을 별도로 저장하지 않습니다. 오류 알림에는 모델, 상태 코드, 시각 등만 포함하고 도안 또는 Gemini 응답 본문은 넣지 않습니다. Cloudflare 자체의 처리와 보관은 Cloudflare 개인정보 처리방침을 따릅니다.
  • Google Gemini API (유료 서비스): 현재 Cloud Billing이 연결된 유료 Gemini API 서비스를 사용합니다. Google은 이 유료 서비스에서 프롬프트와 응답을 Google 제품 개선에 사용하지 않지만, 악용 정책 위반을 탐지·방지하기 위해 제한된 기간 보관할 수 있습니다. 자세한 내용은 Gemini API 약관과 데이터 보관 안내를 확인해 주세요.

민감하거나 기밀인 정보를 포함한 도안은 AI 분석에 보내지 마세요. 광고·추적 SDK는 사용하지 않습니다.

3. 보관과 삭제

프로젝트와 첨부 파일은 사용자가 프로젝트를 삭제하거나 앱을 삭제할 때까지 기기에 보관됩니다. 앱은 백그라운드로 전환될 때 마지막 정상 상태의 프로젝트와 첨부 파일을 앱 전용 저장 공간에 자동 백업하며, 저장소 오류가 발견되면 손상된 저장소와 첨부 파일도 별도 사본으로 보존합니다. 앱에서 내보내는 복구 백업에는 프로젝트 데이터와 첨부 파일이 포함됩니다. 사용자가 백업을 내보내면 선택한 위치에 별도 파일로 보관되며 앱 삭제 시 자동 삭제되지 않으므로 직접 삭제해야 합니다.

AI 분석을 위해 전송된 데이터의 처리는 Cloudflare와 Google의 정책 및 서비스 조건을 따릅니다. Heize는 전송된 도안이나 분석 결과를 자체 서버에 별도 저장하지 않습니다.

4. 문의와 권리

기기에서 프로젝트와 첨부 파일을 삭제할 수 있습니다. 개인정보 관련 문의는 rv6qxfg9mm@privaterelay.appleid.com로 연락해 주세요.

Privacy Policy

Last updated: 2026-10-14
Operator: Jaehun Seo (Heize)
Contact: rv6qxfg9mm@privaterelay.appleid.com

1. Information and purposes

  • Projects and pattern files: Project names, craft type, progress, edited pattern content, and attached PDFs or photos are stored on the device to provide project management. No separate account or sign-in is required.
  • AI pattern analysis: Only when you request analysis and agree to the in-app notice, the file name, text extracted on the device from the selected PDF or photo, and page images needed for analysis are sent through a Cloudflare Worker to the Google Gemini API. AI organizes pattern sections, steps, and options. Up to 40 selected PDF pages are analyzed; for longer PDFs you can choose a range. The source attachment and analysis result are stored on the device when you save the project.
  • Free analysis count: The remaining count may sync through Apple iCloud Key-Value Store. Project content and pattern files are not synced by this feature.
  • Purchases: Unlock purchases and restoration use Apple StoreKit. Apple processes payment information; Heize does not receive card details.
  • Camera: Accessed only when you choose a feature that needs it, such as gauge measurement.

2. Third-party services

  • Cloudflare: Processes the request IP address to route requests and apply per-IP rate limits. The Heize Worker code does not separately store request bodies. Error alerts contain the model, status code, and time; they exclude pattern data and Gemini response bodies. Cloudflare's own processing and retention are governed by its Privacy Policy.
  • Google Gemini API (paid service): Heize currently uses the paid Gemini API service with Cloud Billing connected. Google does not use prompts and responses from this paid service to improve Google products, but may retain them for a limited period to detect and prevent abuse policy violations. See the Gemini API Terms and data retention information.

Do not submit patterns containing sensitive or confidential information for AI analysis. Heize does not use advertising or tracking SDKs.

3. Retention and deletion

Projects and attachments remain on the device until you delete a project or remove the app. When the app moves to the background, it automatically saves a last-known-good copy of project data and attachments in app-only storage. If a store error is detected, the damaged store and attachment files are also preserved separately. Recovery backups exported from the app include project data and attachments. An exported backup is saved to a location you choose and is not automatically deleted when you remove the app; delete it yourself.

Data sent for AI analysis is handled under Cloudflare's and Google's policies and service terms. Heize does not separately store submitted patterns or analysis responses on its own server.

4. Contact and your choices

You can delete projects and attachments in the app. For privacy questions, contact rv6qxfg9mm@privaterelay.appleid.com.

5. Changes

When this policy changes, the last updated date on this page will be revised.
